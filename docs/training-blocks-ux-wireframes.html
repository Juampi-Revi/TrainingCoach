Nueva direccion UX

Del modal tecnico al constructor por patron de ejecucion

La propuesta deja de preguntar por campos aislados y pasa a preguntar por como se hace el bloque: lista de ejercicios, timer guiado, pasadas de running, cardio continuo o recuperacion. Cada decision muestra duracion, descansos y preview del alumno en tiempo real.

Coach entiende Que esta creando, cuanto dura y como se ejecuta.
Alumno entiende Que tiene que hacer ahora, cuanto falta y que sigue.
Sistema escala Running y bici reutilizan la misma logica sin duplicar UX.
Problema 1: el coach elige un tipo tecnico demasiado pronto La UI obliga a pensar en `intervals`, `cardio` o `targetMinutes` antes de pensar el bloque.
Problema 2: la duracion no queda evidente El sistema pide datos pero no devuelve una lectura clara del esfuerzo final.
Problema 3: el alumno cambia de patron sin una gramatica comun Lista, timer, pasadas y cardio libre no se presentan como familias visuales coherentes.

Patrones de bloque propuestos

La UI muestra intencion y modo de ejecucion, no el nombre tecnico interno
Patron 01

Lista de ejercicios

Para calentamiento, fuerza, accesorios y cooldown guiado.

  • Duracion estimada
  • Descanso entre ejercicios
  • Logger por serie / reps
Patron 02

Timer guiado

Para tabata, hiit, emom y amrap con feedback inmersivo.

  • Trabajo, descanso, rondas
  • Tiempo total visible
  • Preview de ejecucion
Patron 03

Pasadas de running

Para series, fartlek y bloques mixtos por tiempo o distancia.

  • Steps ordenados
  • Intensidad por paso
  • Totales de km y tiempo
Patron 04

Cardio continuo

Para zona 2, bici base o trote lineal sin pasos internos.

  • Duracion objetivo
  • Zona / FC / RPE
  • Consigna corta y clara
Patron 05

Recuperacion / movilidad

Para respiracion, elongacion y cierre guiado de la sesion.

  • Lista corta o instrucciones
  • Tiempo total
  • Cierre simple

Resumen de diferencias
Trabaja por repeticiones Fuerza, calentamiento tecnico, EMOM con reps, AMRAP con tareas cerradas.
Trabaja por tiempo HIIT, Tabata, cardio continuo, movilidad, algunos ejercicios sueltos.
Trabaja por distancia Running por pasadas, bici por tramos, remo o assault bike por metros.
Trabaja por intensidad Running/cardio continuo con ritmo, zona de FC, RPE, velocidad o potencia.
